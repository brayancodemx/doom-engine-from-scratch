# Audio opcional

Los efectos de esta carpeta no se incluyen en la publicación pública por
defecto porque su licencia de redistribución no está documentada. El juego
funciona sin ellos: `audio.py` genera sonidos procedurales de respaldo.

Si sustituyes estos archivos por efectos propios o con una licencia compatible,
usa los nombres que espera `audio.py` y conserva la atribución correspondiente.
